# Moscow County — документация

Готовый статический сайт: HTML + CSS + JavaScript. Никакого сервера или сборки не требуется.

## Структура

- `index.html` — главная страница
- `style.css` — дизайн и адаптивная верстка
- `script.js` — поиск по разделам и сочетание Ctrl/Cmd + K
- `assets/logo.png` — квадратная иконка из предоставленного изображения
- `assets/hero-banner.png` — баннер из предоставленного изображения

## Как выложить на GitHub Pages

### Вариант 1 — через браузер

1. Открой GitHub и создай новый **Public repository**, например `moscow-county`.
2. Нажми **Add file → Upload files**.
3. Распакуй этот ZIP на компьютере и перетащи **содержимое папки** в GitHub.
   В корне репозитория должны лежать `index.html`, `style.css`, `script.js` и папка `assets`.
4. Нажми **Commit changes**.
5. Открой **Settings → Pages**.
6. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
7. Нажми **Save**.
8. Через некоторое время GitHub выдаст адрес вида:
   `https://ТВОЙ-НИК.github.io/moscow-county/`

### Вариант 2 — через Git

После распаковки проекта в терминале:

```bash
git init
git add .
git commit -m "Initial Moscow County documentation"
git branch -M main
git remote add origin https://github.com/ТВОЙ-НИК/moscow-county.git
git push -u origin main
```

Затем включи GitHub Pages через **Settings → Pages**, как описано выше.

## Что уже работает

- Нажатие на `Moscow County` в шапке возвращает на `index.html`.
- Поиск реально фильтрует разделы по названию и ключевым словам.
- `Ctrl + K` / `Cmd + K` переводит курсор в поиск.
- Ссылки слева прокручивают страницу к соответствующим карточкам.
- Кнопки `Поддержка` и `Войти` пока являются визуальными заглушками.
- Страница адаптируется под телефон.
- Раздел «История изменений» намеренно не добавлен.
- Иконки у пунктов левого меню не используются.

## Важно

Все изображения в `assets` — локальные, поэтому сайт нормально работает на GitHub Pages без внешних хостингов.
